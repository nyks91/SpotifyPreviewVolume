# SpotifyPreviewVolume

A BetterDiscord plugin by [naykis](https://github.com/nyks91) that adds volume control to available Spotify track previews in chat.

## Features

- Spotify-style and minimal preview players.
- Adjustable volume, optional fixed starting volume, and playback seeking.
- Switch between the original Spotify embed and the custom player; optionally hide the switch.
- Track artwork, Spotify's track colors, artist links, and explicit-content badges when available.
- GitHub release update checks with confirmation before installation.
- A changes screen shown once per installed version, with a button to reopen it in settings.

The custom player plays Spotify's short audio previews, not full tracks. Some tracks have no available preview. The original Spotify embed remains accessible.

## Installation

1. Download `SpotifyPreviewVolume.plugin.js` from the [latest release](https://github.com/nyks91/SpotifyPreviewVolume/releases/latest).
2. In Discord, open **Settings → BetterDiscord → Plugins → Open Plugins Folder**.
3. Place the file in that folder and enable **SpotifyPreviewVolume**.

No additional plugin library is required. Keep the filename `SpotifyPreviewVolume.plugin.js` for updates to work.

Updates are checked when the plugin starts and installed only with your confirmation. View version notes from the plugin settings.
